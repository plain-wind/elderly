# 智慧养老服务平台

一个基于 Vue 3 + TypeScript + Element Plus 开发的智慧养老服务管理平台，为社区老年人提供全方位的健康监测、志愿服务和活动管理服务。

## 项目特性

### 核心功能

- **健康监测**：老年人身体体征数据实时监测与管理
- **志愿服务**：志愿者服务申请与审核系统
- **活动管理**：社区活动发布、报名与详情查看
- **用户管理**：管理员登录与权限控制

### 技术栈

- **前端框架**：Vue 3 + Composition API
- **类型系统**：TypeScript
- **UI 组件库**：Element Plus
- **路由管理**：Vue Router
- **构建工具**：Vite
- **样式管理**：SCSS
- **状态管理**：Vue 3 响应式 API

### 项目结构

```
/src
  /assets            # 静态资源（图片、样式等）
  /components        # 可复用组件
  /router            # 路由配置
  /types             # TypeScript 类型定义
  /utils             # 工具函数
  /views             # 页面组件
    /admin           # 管理员页面
      /active        # 活动管理
      /bodyData      # 健康数据管理
      /volunt        # 志愿服务管理
    /index           # 首页和登录页面
  App.vue            # 根组件
  main.ts            # 入口文件
```

## 快速开始

### 环境要求

- Node.js 16.0+
- pnpm 7.0+（推荐）或 npm 8.0+

### 安装依赖

使用 pnpm（推荐）：

```bash
pnpm install
```

或使用 npm：

```bash
npm install
```

### 开发模式运行

```bash
pnpm run dev
# 或
npm run dev
```

项目将在 `http://localhost:5173` 启动开发服务器。

### 构建生产版本

```bash
pnpm run build
# 或
npm run build
```

构建产物将生成在 `dist` 目录中。

## 页面导航

### 管理员功能

- **健康数据**：查看和管理老年人的身体体征数据
- **志愿服务**：审核志愿者申请，管理服务记录
- **活动管理**：发布和管理社区活动

### 功能模块

#### 1. 健康监测模块

- 实时监测老年人的血压、心率、血氧等身体指标

- 历史数据趋势分析

#### 2. 志愿服务模块

- 志愿者申请与审核流程
- 服务类型管理（陪伴聊天、打扫卫生、购物等）

#### 3. 活动管理模块

- 活动发布与详情管理
- 参与人员统计
- 活动评价与反馈

## 项目配置

### 环境变量

项目使用 `.env` 文件管理环境变量，包含 API 地址等配置。

### 路由配置

路由配置位于 `src/router/index.ts`，包含登录、管理员和各功能模块的路由定义。

### 类型定义

TypeScript 类型定义位于 `src/types/index.ts`，包含用户、活动、志愿者等数据类型。

## 开发指南

### 添加新页面

1. 在 `src/views` 目录下创建新的页面组件
2. 在 `src/router/index.ts` 中添加路由配置
3. 实现页面功能和样式

### 添加新组件

1. 在 `src/components` 目录下创建新的组件
2. 在需要使用的页面中导入并使用

### 添加新类型

在 `src/types/index.ts` 中添加新的 TypeScript 类型定义。
